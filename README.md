# Unit Converter

A simple and user-friendly **Python-based Unit Converter** that allows users to convert values between different units.

## Features

* 📏 **Length Conversion**

  * Meter ↔ Kilometer
  * Meter ↔ Centimeter
  * Kilometer ↔ Miles

* ⚖️ **Weight Conversion**

  * Kilogram ↔ Gram
  * Kilogram ↔ Pound

* 🌡️ **Temperature Conversion**

  * Celsius ↔ Fahrenheit
  * Celsius ↔ Kelvin

* ⏰ **Time Conversion**

  * Hours ↔ Minutes
  * Minutes ↔ Seconds
  * Hours ↔ Seconds

* 💧 **Volume Conversion**

  * Liter ↔ Milliliter
  * Liter ↔ Gallon

## Technologies Used

* Python
* Command Line Interface (CLI)

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python main.py
```

4. Select the required conversion option.
5. Enter the value to convert.
6. The converted result will be displayed.

## Example

```text
UNIT CONVERTER

1. Length
2. Weight
3. Temperature
4. Time
5. Volume

Enter your choice: 1
Enter conversion: 1
Enter value: 5000

Result: 5.0 km
```
